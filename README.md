# ⚡ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/zaid1234-11/portfolio.git
```

Move into the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open in browser:

```bash
http://localhost:8080
```
